# متن و صحنه‌های ویدئوی دمو (حدود ۵ دقیقه)

**هدف:** هر بخش یکی از معیارهای داوری را نشان بدهد. ستون «نشان بده» کاری است که روی صفحه انجام می‌شود و ستون «بگو» متن صداگذاری است.

**آماده‌سازی قبل از ضبط**
- `.env`: `LIARA_MODE=mock`, `MOCK_LLM=true`, `ALLOW_DESTRUCTIVE=true`, `MOCK_LATENCY_SCALE=1`. (اگر توکن واقعی داریم، بخش ۷ را با حالت واقعی ضبط کنید.)
- `pnpm dev` و مرورگر روی `http://localhost:3200`، پوسته‌ی روشن، زوم ۱۱۰٪، پنجره‌ی ۱۴۴۰×۹۰۰.
- پوشه‌ی `var/` را پاک کنید تا تاریخچه خالی باشد.
- یک بار کل سناریو را تمرین کنید (هر بخش زیر یک دقیقه یا کمتر).
